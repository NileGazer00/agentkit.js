QUICKSTART

From zero to agent in 2 minutes

1
Install
npm install agentkit
2
Define Tools
const weather = tool({
  name: 'get_weather',
  execute: async ({city}) => {
    return await fetch(url)
  }
})
3
Create Agent
const agent = new Agent({
  model: 'gpt-4o',
  tools: [weather],
  strategy: 'react'
})
4
Run
const result = await agent.run(
  "Weather in Tokyo?"
)
console.log(result.answer)
